# 家族の医療カード

急な受診・救急搬送のときに見せる、家族の病歴・意向（ACP）・内服薬をまとめたカード。
ホーム画面に追加すると、ふつうのアプリのように全画面で起動し、オフラインでも開けます。

**公開URL: https://r22526t-eng.github.io/first-medical-card/**

## 使い方（スマホ）
1. 上のURLをブラウザで開く
2. iPhone: 共有メニュー →「ホーム画面に追加」／Android: メニュー →「アプリをインストール」
3. **追加されたアイコンから起動して入力する**

## データについて
- 入力内容は **開いた端末のブラウザの中だけ** に保存されます。外部には一切送信されません
- このリポジトリに個人情報は含まれていません
- iPhoneではホーム画面アプリとSafariで保存場所が分かれます。入力は必ずホーム画面のアイコンから開いた画面で行ってください

## 構成
| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（単一ファイル） |
| `manifest.json` | アプリ名・アイコン・全画面起動の設定 |
| `sw.js` | オフライン用サービスワーカー |
| `icon-*.png` | アプリアイコン |
